# Employee Payroll System - Java JDBC and MySQL

Learning Problem (LP03) - Section 3: JDBC CRUD for the Employee Payroll problem.

This repository is built incrementally using Git feature branches (UC1 to UC6).
The complete implementation and documentation are maintained on the `develop`
branch. The `main` branch intentionally contains only this initial README.

## Technologies

- Java 22
- MySQL 8.0
- JDBC (MySQL Connector/J)
- Maven
- JUnit 5
- Git and GitHub
